## ⚫ About

Full-stack developer who likes taking a product from database schema to polished UI. Comfortable working with PHP and CodeIgniter on the backend, React and Next.js on the frontend, and currently extending that range into mobile with Expo. More interested in systems that stay clean as they scale than in one-off demos — clear architecture, sensible API design, and code a teammate can pick up without a walkthrough.

**Currently open to:**
- Collaborative full-stack or mobile projects
- Open-source contributions
- Conversations about system design & API architecture
